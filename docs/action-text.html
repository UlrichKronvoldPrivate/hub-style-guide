Skagen as text

The fill value of an action colour is tuned for buttons and bars, where 3:1 is the bar. As 14px text — links, quiet buttons — it has to clear 4.5:1 (AA) and should clear 7:1 (AAA). This page computes that against the real glass, over the densest stop of every seed's sky, for the fill value and two text candidates in each theme.
