color/action

Klint by default, Panton on purpose

the argument

Danish design has always run an argument with itself. Kaare Klint measured furniture against the human body and built systems out of it: proportion, modules, restraint. Verner Panton answered with saturated orange rooms and moulded plastic. Both are Nordic. Only one of them is the postcard.

This system keeps Klint's rigour in the structure and rations Panton's voltage to the places where it changes what you do. Pastels are the material; cobalt and flare are the current running through it. When a screen looks loud, the voltage rule has been broken somewhere.

Voltage

Cobalt is the current: interaction, focus, edges, selection. Flare is the accent that appears once on a screen, or not at all. Neither is ever a background wash, and neither carries meaning that semantic colour should carry.

cobalt#2B3FC4  action, edges
flare#E8358C  emphasis only
The five percent rule

Cobalt and flare together cover no more than a twentieth of any screen: primary buttons, one live edge, a focus ring, the single number that matters. Past that they stop reading as signal and start reading as decoration.

One family carries the whole system. Schibsted Grotesk was drawn for a Norwegian newsroom, so it holds at 12px in a dense table and at 96px in an opener, and its Nordic diacritics are properly drawn rather than bolted on. Personality comes from weight and tracking, not from a second display face.

JetBrains Mono appears only where characters need to line up: code, hex values, identifiers, token names. It is a tool, not a voice. Never set a label in mono to make it look technical.

Space and shape

--hub-space-*, --hub-radius-*

Everything is a multiple of eight

Four exists only for optical nudges inside a control. The dot grid behind this page steps every 24px, three modules, so any plate you draw lands on it.

4  8  12  16  24  32  48  64  96

Two radii, chosen by role

Controls take 4px so they read as machined. Plates take 12px so they read as objects you could pick up. Pills are reserved for status, never for buttons. One radius on everything flattens the hierarchy.

Elevation is material, not fog

A raised plate gets a hairline plus a tight shadow tinted with spruce, never a soft grey blur stamped under every block. Glazes do not lift at all, because a painted surface casts nothing.

0 1px 0 hairline, 0 10px 26px -18px rgba(19,36,32,.55)

Motion answers an action

Expanding, confirming, connecting: 160–240ms on cubic-bezier(.2,.7,.3,1). One orchestrated moment per page is allowed, like the wiring that drew itself above. Scroll-triggered fades on every section are banned, and reduced motion is always honoured.

Node anatomy

Every node is a header and a body. The header holds a category square in a glaze and the node's name at label size. The body holds one line of the node's real configuration in mono, so a graph is readable without opening anything.

Glaze means category

The category square is the only place a glaze appears inside a graph. Sources take glacier, transforms take lichen, outputs take flare, a failing node takes the danger token. Never fill a whole node with a glaze; the graph turns into confetti.

Animate only real flow

A marching dashed edge means data is moving right now. If it animates while nothing runs, it is decoration and it goes. Background dots step at 24px to match the page grid, so a canvas embedded in a page lines up with the page.

A canvas is still a document

Keyboard focus rings, a visible selected state and labels that survive 50% zoom are requirements, not polish. If a node is unreadable when zoomed out, its body line is too long.

The rules

read before you build

Voltage stays under five percent

Cobalt and flare are current, not paint. If a screen feels loud, measure the coloured area.

Glazes stay flat

No gradient, no blur, no shadow on a pastel field. It is fired ceramic, not a lighting effect.

Lines mean connection

A rule, a border or an edge states that two things relate. Nothing gets drawn to fill space.

One family, weight does the work

No second display face. A heading that needs more presence needs more weight or tighter tracking.

Radius is a role, not a habit

Four for controls, twelve for plates, pills for status. Anything else is a decision you have to defend.

Semantic colour is separate

Success, warning and danger own their tokens. The accent never stands in for state.

Tells to avoid

the point of all this
Reads as generated
  • Cream ground with a serif display and a terracotta accent
  • Tracked-out capitals as an eyebrow above every heading
  • Identical rounded cards under the same soft grey shadow
  • Numbered markers on content that is not a sequence
  • An arrow glued to the end of every button and link
  • A purple-to-blue gradient behind the opening headline
  • Meta lines strung together with middle dots
Reads as ours
  • Cool porcelain ground under a green-black ink that has hue
  • Headings that earn presence through weight and tight tracking
  • Plates that differ by material: flat glaze, hairline, or lifted
  • Structure that encodes a real dependency between two things
  • Buttons that name the outcome, then confirm it in the same words
  • One saturated moment on an otherwise quiet page
  • Values in mono because the digits need to line up
