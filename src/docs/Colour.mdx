# Colour

Every value below is read off the live document, so this page shows the true
token value in whichever theme the **Theme** control is set to. Switch it to
Winter night and the swatches follow.

## Ground and ink

Porcelain is cool and faintly green — the colour of low winter daylight through
glass. Never cream. Spruce is a green-black rather than a tinted grey, so large
dark fields still carry hue.

## Glazes

Flat ceramic fields for large surfaces, empty states and node categories. No
gradient, no blur, no shadow — a painted surface casts nothing. Each glaze has a
daylight value and a winter-night value, so dark mode is a considered palette
rather than an inversion.

<GlazeGrid />

Text on a glaze is always `--hub-color-ink-on-glaze`.

## Voltage

Cobalt is the current: interaction, focus, edges, selection. Flare is the accent
that appears once on a screen, or not at all.

### The five percent rule

Cobalt and flare together cover no more than a twentieth of any screen: primary
buttons, one live edge, a focus ring, the single number that matters. Past that
they stop reading as signal and start reading as decoration.

Two flares on a screen means neither is the one.

## Status

Separate from voltage, always. The accent never stands in for state, and state
never borrows the accent — which is why danger is a rust red rather than a
brighter version of flare.

## Both themes

Only semantic tokens change between themes; primitives never do, and components
never restyle inside a theme block. There are three states to design for, not
two: an explicit `data-theme="light"`, an explicit `data-theme="dark"`, and the
un-stamped default where only `prefers-color-scheme` separates them. `tokens.css`
handles all three, and treats `.dark` as an alias so React Flow's
`colorMode` works with no extra wiring.
