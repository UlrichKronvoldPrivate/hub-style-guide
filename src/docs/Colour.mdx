# Colour

Every value below is read off the live document, so this page shows the true
token value in whichever theme the **Theme** control is set to.

rather than a tinted grey, so large dark blocks still carry hue.

## Action

Skagen — sea petrol — is the one action colour: focus rings, selection, links,
and the single chart mark that carries the point. **The primary button is not
Skagen; it is the ink block**, the same black as the current nav item.

<Swatches tokens={[
  ['--hub-color-action', 'action — fills, focus, selection'],
  ['--hub-color-action-text', 'action as text — links, quiet buttons'],
  ['--hub-color-action-soft', 'action, soft'],
]} />

Small type takes the text step, never the fill value: the fill clears AA but
not AAA as 14px text by day and is marginal by night; the text step is deeper
by day and paler by night and clears everywhere.

## Three theme states

Only semantic tokens change between themes; primitives never do, and
components never restyle inside a theme block. There are three states to
design for: an explicit `data-theme="light"`, an explicit `data-theme="dark"`,
and the un-stamped default where only `prefers-color-scheme` separates them.
`tokens.css` handles all three, and treats `.dark` as an alias so React Flow's
`colorMode` works with no extra wiring.
