# Kridt

The house style shared by every hub app. Its job is consistency across projects,
and a look that reads as one studio's work rather than one model's default.

*Kridt* is Danish for chalk. One flat ground. White sheets that touch and are
divided by hairlines rather than gaps. Spruce as the black. No shadows, no
gradients, no glass. Colour appears only where it means something — status,
and the one action colour. Use **Theme** in the toolbar to see it at night.

## The argument

Danish design runs an argument with itself. Kaare Klint measured furniture
against the human body and built systems out of it — proportion, modules,
restraint. Verner Panton answered with saturated orange rooms and moulded
plastic. Both are Nordic; only one is the postcard. Kridt is Klint's side, all
the way: the pop comes from contrast and figure, not from atmosphere.

## Six rules

**Colour only where it means something.** Status pills and the action colour.
Everything else is ink on paper. A third colour on a screen is decoration.

**Lines, not gaps, and never shadows.** Regions of a sheet touch and share a
1px hairline. Depth does not exist; hierarchy is size, weight and position.

**Lines mean connection.** A rule, border or edge asserts that two things
relate. Nothing is drawn to fill space.

**One family, weight does the work — quietly.** Schibsted Grotesk alone, at
500–600 for headings and figures, never 800.

**Radius is a role, not a habit.** 0 for a cell inside a sheet, 8px for
controls, 14px for a standalone sheet, pills for buttons and status, circles
for icon buttons.

**Semantic colour is separate.** Success, info, warning and danger own their
tokens. The action colour never stands in for state.

## Using it in an app

Load the fonts, the token file and the layout file, then style from custom
properties. Never a literal hex — if a value you need has no token, add the
token.

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Schibsted+Grotesk:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap">
<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="layout.css">
<link rel="stylesheet" href="node_modules/boxicons/css/boxicons.min.css">
```

```css
.thing {
  background: var(--hub-color-surface);
  border-top: 1px solid var(--hub-color-line);   /* regions share lines, not gaps */
  color: var(--hub-color-ink);
}
```

Tokens layer in three tiers, the way Material 3 layers reference, system and
component tokens:

```
--hub-skagen-40   →   --hub-color-action   →   --hub-tab-indicator
   primitive              semantic                  component
```

A component never names a primitive. That indirection is what makes a theme
swap possible — and it is why the **Theme** control re-themes every story here,
canvases included, without a single component knowing about it.

## Where things live

`skills/hub-design-system/references/tokens.css` and `layout.css` are the
source of truth, and they live with the skill rather than under `src/`, so the
guidance Claude loads and the components rendered here can never drift apart.

## Tells to avoid

These read as generated. If a review turns one up, it is a defect.

| Tell | Instead |
|---|---|
| Cream ground, serif display, terracotta accent | Flat porcelain, one grotesque, spruce |
| Tracked-out capitals as an eyebrow above headings | Let the heading start the section |
| Identical rounded cards under the same grey shadow | One sheet, regions divided by hairlines |
| A gradient behind a headline, a glass or blur effect | Flat; colour comes from the marks |
| `01 / 02 / 03` markers on non-sequential content | Number only real sequences and timelines |
| An arrow glued to every button and link | The verb already says what happens |
| Near-black `#111` standing in for black | Spruce `#132420`, a dark that has hue |
| Mono for small labels, to look technical | Mono only where characters must align |
| A coloured button for every action | One ink primary; the rest paper or quiet |
