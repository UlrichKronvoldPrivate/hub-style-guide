# Space and shape

## Everything is a multiple of eight

Four exists only for optical nudges inside a control. Layout does the spacing:
flex or grid with `gap`, never per-element margins that collapse or double.

<SpaceRamp />

The dot grid is engineer's paper for canvases — React Flow draws its own at
24px, and `.hub-paper` puts one on anything else that wants it. It is no
longer on the page ground; the sky is.

## Radius has a range, and still means role

Controls take 10px. Plates take 20px. The one tile that leads a page takes
28px. Pills are reserved for status, never for buttons or filters.

<Shapes />

One radius on everything flattens the hierarchy. Radius also sets register: a
full stadium pill reads as a consumer tag, so in an instrument UI where every
status is a machine state, square the status marker to the control radius
instead.

## Elevation is tone, not shadow

Five surface levels, each a step more opaque — lowest, low, surface, high,
highest. Lift something by moving it up a level, not by drawing under it. A
dialog is simply the highest surface over a scrim. There are no drop shadows
anywhere in the system.

```css
--hub-shadow-plate:   inset 0 1px 0 var(--hub-edge);   /* the lit top edge, not a shadow */
--hub-shadow-overlay: inset 0 1px 0 var(--hub-edge);
```

Every surface is translucent and needs `backdrop-filter: var(--hub-glass)` to
read as glass. The component recipes include it.

**Not everything is a plate.** Three separations, picked by role: a tonal cell
(a stop of the sky at tint-alpha), a hairline, or a step up in surface level. A
screen picks one per object type. A page where some things are tonal and others
are lifted, for the same kind of content, is a mistake.

## Motion

Motion answers an action: expanding, confirming, connecting. 160–240ms on
`--hub-ease`. One orchestrated moment per page is allowed. **Banned:**
fade-and-slide-up on every section as it scrolls into view, and a hover-lift on
every card. `prefers-reduced-motion` is honoured globally in `tokens.css`.
