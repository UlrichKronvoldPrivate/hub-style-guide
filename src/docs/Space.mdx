# Space and shape

## Everything is a multiple of eight

Four exists only for optical nudges inside a control. Layout does the spacing:
flex or grid with `gap`, never per-element margins that collapse or double.
Regions inside a sheet take `--hub-space-5` of padding.

<SpaceRamp />

The dot grid is engineer's paper for canvases — React Flow draws its own at
24px, and `.hub-paper` puts one on anything else that wants it. It is not on
the page ground; the ground is flat.

## Radius is a role

A cell inside a sheet has none — the sheet has the corners. Controls and nav
items take 8px. A sheet that stands alone, a dialog, a toast: 14px. Buttons
and status are pills. Icon buttons and discs are circles.

<Shapes />

One radius on everything flattens the hierarchy. Radius also sets register: a
full stadium pill reads as a consumer tag, so in an instrument UI where every
status is a machine state, square the status marker to the control radius
instead.

## There are no shadows

Regions of a sheet touch and share a 1px hairline. Depth does not exist;
hierarchy is size, weight and position. A dialog is a sheet over a scrim.

```css
--hub-shadow-plate:   none;   /* kept so older CSS keeps working */
--hub-shadow-overlay: none;
```

**Not everything is a plate.** Three separations, picked by role: a hairline,
a sunken band (`--hub-color-surface-sunken`), or a standalone sheet with
corners. A screen picks one per object type. A page where some things are
sunken and others are sheets, for the same kind of content, is a mistake.

## Motion

Motion answers an action: expanding, confirming, connecting. 160–240ms on
`--hub-ease`. One orchestrated moment per page is allowed. **Banned:**
fade-and-slide-up on every section as it scrolls into view, and a hover-lift on
every card. `prefers-reduced-motion` is honoured globally in `tokens.css`.
